# 成果物の表記ルール

## 絵文字と強調文字の使用

- ユーザーへの表示（Claude の出力）: 絵文字や強調文字の使用可
- 成果物（JIRA、PR、ドキュメント）: 絵文字と強調文字を使用しない
  - JIRA の説明文、コメント
  - GitLab の PR タイトル、説明文
  - docs/ ディレクトリに出力するドキュメント
  - コミットメッセージ

禁止される表記例:

- 絵文字: ✅ ❌ 🔍 📝 など
- 強調文字: **太字** _斜体_ など

許可される表記:

- 通常のテキスト
- 箇条書き（- または 1.）
- コードブロック（```）
- インラインコード（`code`）
